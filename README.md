# Portfólio de Guilherme Niederle

Portfólio profissional bilíngue com duas formas de navegação: uma experiência original de plataforma 2D em pixel art e uma versão institucional convencional. O modo jogo é a experiência inicial.

## Planejamento

As decisões aprovadas de produto, conteúdo, interação, responsividade, direção artística e arquitetura técnica estão registradas em [docs/planejamento.md](docs/planejamento.md).

Agente principal: [.codex/agents/portfolio-architect.toml](.codex/agents/portfolio-architect.toml).

Skills especializadas criadas em `.agents/skills/`: `frontend-architecture`, `pixel-art-environment`, `responsive-accessibility` e `testing-quality`.

O currículo em [docs/curriculo.pdf](docs/curriculo.pdf) é a fonte principal para as informações profissionais. Não devem ser inventados projetos, resultados, métricas ou competências.

## Estado

Etapa atual: planejamento visual, funcional e técnico concluído; quatro skills especializadas criadas; scaffold técnico inicial criado e validado. React, Vite e TypeScript estão configurados, assim como Vitest e Playwright. Os testes iniciais passaram, a verificação de TypeScript passou e o build de produção foi concluído com sucesso.

A conclusão do scaffold não representa o início da implementação das funcionalidades do portfólio. Modos jogo e institucional, cenário, movimentação, painéis e conteúdo ainda não foram implementados. Assets finais e deploy também permanecem pendentes.
